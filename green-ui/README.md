## 文件边界

- `index.html` 与原版脚本、CSS 是创建时复制的快照。
- `green-ui.css`：独立视觉覆盖层。
- `green-ui.js`：仅负责推子填充与音量读数，不处理声音、音符或播放调度。
- `groove-app.js` 的预设/收藏存储键改为 `guitarGrooveGreenProject` / `guitarGrooveGreenFavorites`，避免预览覆盖原版浏览器数据；调式、风格与材料名称改为读取共用目录。
- `practice-catalog.js` 共用 10 种音阶、风格、节奏材料和七和弦规则，音程数据与和声运算来自 `groove-engine.js`。琶音支持全部 10 种；五声 / Blues 的七和弦采用引擎的母调规则。
- `ear-engine.js`、`ear-audio.js`、`ear-app.js`、`ear.css` 实现独立听感菜单（详见根目录 HANDOFF.md）。
- `build.cjs` 同步生成根 `index.html`、两个 outputs 入口和 `publish/index.html`，内容相同。
- 根目录 `index.html` 已变为构建产物。主源码是本目录；旧版可从 Git 提交 `b33edbb` 恢复。

## 构建

在项目根目录执行：

```sh
node green-ui/build.cjs
```

以后只修改本目录主源码并构建，不再从旧 assets 自动同步。不要直接修改根目录或 outputs/publish 的 HTML。

## 验证与手动验收

已对副本运行现有五组音乐理论与播放调度测试，并检查脚本语法、构建内联和原版文件完整性。

浏览器工具拦截了本地文件预览，尚未完成实际渲染、iPad 触控和听感验收；本次没有改变音频算法。

建议按以下顺序手动检查：

1. 琶音练习：选 Cmaj7，确认蓝色根音、绿色和弦音，上音名/下简谱；拖动把位推子。
2. 动机训练：打开弹窗，调整音量并播放。
3. 律动生成器：收起/展开设置；打开音轨与音色设置，拖动三条音量推子，确认读数变化。
4. 律动生成器：播放、空格停止、循环、速度阶梯与专注模式；检查当前 BPM 与音量。
5. 指板知识和常用和弦指型：检查表格、语义颜色标签、指型图和窄屏横向滚动。
6. 在 iPad mini 横屏与竖屏检查控件触达、推子拖动和底部播放条遮挡情况。

## 听感练习验收（2026-09-24）

执行 `node tests/ear-training.test.cjs` 验证生成、共用调式、六弦位置、鼓组和模拟时钟循环。

1. 进入「听感练习」，默认随机主音 / Ionian 大调 / 4 音 / 80 BPM / 播放 3 遍。
2. 选 1–8 个音和多种节奏，生成新题。更改生成参数需要点击生成；播放速度、遍数、伴奏参数对同题生效。
3. 开始播放，检查三遍后停止，间隔小节静音。无限循环用停止或空格结束（输入控件聚焦时保留原生键盘行为）。
4. 测试新题默认隐藏、播放后隐藏，以及手动切换显示；答案默认不渲染，揭晓后显示音符卡、节奏时间线、精确落点和六弦位置。
5. 单点音符试听、重听、改变 BPM，保持同一题；下一题才重新随机。
6. 切换菜单、离开页面、载入音色时停止，均应取消播放。风格与调式选项来自律动生成器共用目录，默认 Ionian。
7. 仅选 Shuffle / 切分 / 3-3-2 等完整分组时，无法组成指定音符数会明确报错，不悄悄改变音符数量或添加未选材料。

实际浏览器渲染、iPad 触控与音频听感仍需在本地打开页面验收；代码测试不能替代设备听音。
