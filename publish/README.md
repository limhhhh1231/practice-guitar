# 一起练琴吧

Studio Green 正式版：六弦吉他和弦琶音、律动生成、听感练习、指板知识、常用和弦指型。

本目录由项目根目录的 `node scripts/build.cjs` 生成。维护源码请修改 `green-ui/`，不要直接修改本目录 HTML。

本目录为可直接部署的静态网站。将 index.html、assets 文件夹和 .nojekyll 上传至 GitHub 仓库根目录，在 Settings → Pages 中选择 Deploy from a branch，选择 main 和 / (root)，保存即可。

首次播放需要点击播放按钮以启用浏览器音频。

音色来源及许可见 [采样说明](assets/ATTRIBUTION.md)。
